### 4. Scalability Check (Step 4) – Suggested Improvement
**Adopt an Asynchronous Event‑Driven Architecture with Distributed Caching**

- **Distributed Cache**: Introduce a clustered Redis layer (read‑through/write‑through) for frequently accessed data, eliminating many direct DB hits.
- **Container Orchestration**: Run the Application Tier in a Kubernetes cluster with Horizontal Pod Autoscaling based on CPU, memory, and queue depth.
